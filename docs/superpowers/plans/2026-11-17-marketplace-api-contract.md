# Marketplace API contract

Prefix/api/v1, decimal money/quantity encoded as strings; auth Bearer existing session. All mutations error {code,message,request_id}. Auth user.role admin/farmer/customer. Checkout/bids/auction confirmation require Idempotency-Key header (browser crypto.randomUUID retained on retry).

## Auth/profile
POST /auth/register {name,email,password,role:farmer|customer} ->{token,user}; POST /auth/login {email,password} same. Existing logout/demo retained. GET /me ->{id,name,role,email?,preferences}. GET/PATCH /market/profile fields public_name,bio,district,area,latitude?,longitude?,phone (private); result includes verification_status. Farmer/customer support; coords optional, BD bounds only. GET /market/farmers/{id} public excludes coordinates/phone.

## Products
GET /market/products?q=&category=&unit=&sort=nearby|nearest|price_asc|price_desc|newest&lat=&lon=&offset=0&limit=20&available=true ->{items:Product[],total,offset,limit,has_more,notice}. Without coordinates sort falls back to relevance/newest, allBD available; no20km cutoff. GET /market/nearby aliases defaultsort. GET /market/products/{id}->Product. Farmer POST /market/products {farm_id,name,category:vegetables|fruits|rice_grains|pulses|other,description,price_bdt,unit:kg|g|piece|bundle|crate,quantity_step,stock_quantity,minimum_order_quantity:null,maximum_order_quantity:null,status:draft|published|paused|archived,harvest_date?,available_from?,pickup_enabled:true,delivery_enabled:false,nationwide_delivery:false,delivery_districts:[],delivery_fee_bdt:'0'} ->Product. Location from owned farm's consented coordinates or marketplace profile, rounded before storage/discovery. Profile district required. PATCH same mutable fields +expected_version REQUIRED. Immutable unit/step/farm after order/auction. Images POST /market/products/{id}/images multipart image; DELETE /market/products/{id}/images/{imageid}; GET samepath returns image bytes (public ifpublished, otherwise authorizedowner/admin/orderparticipant). Max6images.
Product={id,farmer_id,farmer_name,verification_status,farm_id,name,category,description,price_bdt,currency:'BDT',unit,quantity_step,stock_quantity,auction_reserved_quantity,minimum_order_quantity,maximum_order_quantity,status,version,district,area,distance_km:number|null,nearby:boolean,images:[{id,url}],pickup_enabled,delivery_enabled,nationwide_delivery,delivery_districts,delivery_fee_bdt,harvest_date,available_from,auction:AuctionSummary|null,moderation_status,created_at,updated_at}. Public excludes coordinates and privatecontacts.

## Addresses/cart/checkout/orders
GET/POST /market/addresses fields name,phone,line1,district,area,country:'Bangladesh',latitude?,longitude?; DELETE /market/addresses/{id}.
GET /market/cart ->{items:[{id,quantity,product,line_total_bdt}],subtotal_bdt,quote_hash,currency:'BDT',notice}. POST /market/cart/items {product_id,quantity} sets quantity (no hidden default MOQ); PATCH /market/cart/items/{id} {quantity}; DELETE same. Customer only. Optional MOQ validated backend; no stock reserved untilcheckout.
POST /market/orders {address_id,quote_hash,fulfillment:{PRODUCT_ID:'pickup'|'delivery'}} ->Order. Idempotency-Key required. No bid required. Server validates all lineitemsatomically and clears cart on success. One order has seller_orders grouped seller/farm/method. Delivery fee=max configured listing fee pergroup, disclosed in cart/checkout. GET /market/orders paginated ->{items,total,...}; GET /market/orders/{id} full onlybuyer/assignedseller/admin, seller sees onlytheirgroups. POST /market/orders/{id}/cancel {reason} buyer, pendinggroups only. PATCH /market/seller-orders/{id} {status,reason?,cash_received:false} farmer/admin; pickup flow pending→confirmed→preparing→ready_for_pickup→delivered; delivery uses out_for_delivery. Order moneydecimalstrings. Never gatewaypaid: payment_status demo_unpaid|cash_recorded. Cash flag explicitly records unverified seller report.
Order={id,customer_id,created_at,status,payment_status,total_bdt,currency,auction_id,seller_orders:[{id,farmer_id,farm_id,fulfillment,status,payment_status,subtotal_bdt,delivery_fee_bdt,total_bdt,destination:{private fields},items:[{product_id,name,unit,quantity,unit_price_bdt,line_total_bdt}],expires_at}],notice}.

## Auctions
Farmer POST /market/auctions {product_id,lot_quantity,starting_bid_bdt,minimum_increment_bdt,starts_at,ends_at,reserve_price_bdt:null,draft:false}->Auction. Draft POST /market/auctions/{id}/publish; PATCH draft fields; POST /market/auctions/{id}/cancel {reason}. GET /market/auctions (paginated), GET /market/auctions/{id}. POST /market/auctions/{id}/bids {amount_bdt,confirm:true} (customer+idempotency). POST /market/auctions/{id}/confirm {address_id,fulfillment:'pickup'|'delivery'} winner createsunpaidOrder (idempotency). POST /market/auctions/{id}/settle safelyrefreshstate usingservertime; noforcedearlyend.
Auction={id,product_id,product_name,farmer_id,lot_quantity,unit,starting_bid_bdt,minimum_increment_bdt,highest_bid_bdt,state,starts_at,ends_at,server_time,winner_id(onlyself/seller/admin otherwise null),winner_is_you,bid_count,bids:[{id,bidder_alias,amount_bdt,created_at,is_yours}],reserve_met,confirmation_deadline,confirmed_order_id,can_bid,notice}. Owners/admin alsoreserveprice; public no bidder realidentity.

## Dashboard/admin/support exact shapes
GET /market/farmer/dashboard ->{profile,products:Product[],orders:Order[],auctions:Auction[],notifications:Notification[],sales:{booked_bdt,delivered_bdt},counts}. GET /market/customer/dashboard ->{profile,orders:Order[],bids:[{id,auction_id,amount_bdt,created_at,auction:Auction}],winning_auctions:Auction[],favorites:Product[],notifications:Notification[],counts}.
GET /market/addresses ->Address[]; POST AddressCreate; DELETE /market/addresses/{id}. GET /market/favorites ->Product[]; POST /market/favorites/{productid}, DELETE same. GET /market/notifications ->Notification[] {id,title,message,entity_type,entity_id,read,created_at}; PATCH /market/notifications/{id} {read:true}. POST /market/reports {product_id? or order_id?,reason}; POST /market/reviews {product_id,seller_order_id,rating1..5,comment}. GET /market/products/{id}/reviews ->{items,total,...}.
GET /admin/market/dashboard ->{users:[safe_user+verification_status],products:Product[],orders:Order[],auctions:Auction[],reports:Report[],audit:Audit[],analytics:{order_count,product_count,user_count,booked_bdt,delivered_bdt},policy}. These are latest100; counts are aggregate, paginated /admin/market/{users|products|orders|auctions|reports|audit} supports offset/limit for history. PATCH /admin/market/users/{id} {is_active:boolean,reason:string}; PATCH /admin/market/farmers/{id} {verification_status:unverified|pending|verified|rejected,reason}; PATCH /admin/market/products/{id} {moderation_status:visible|hidden,reason}; PATCH /admin/market/reports/{id} {status:open|resolved|dismissed,admin_note}; PATCH /admin/market/policies accepts marketplace_enabled,require_verified_farmer,max_bids_per_minute,winner_confirmation_hours,order_acceptance_hours (non-null values).
Auction response: id,product_id,product:Product(no recursive auction),farmer_id,lot_quantity,unit,starting_bid_bdt,minimum_increment_bdt,highest_bid_bdt?,starts_at,ends_at,confirmation_deadline?,state,winner_is_you,confirmed_order_id?,reserve_met?,bids:[{id,amount_bdt,created_at,bidder_alias,is_yours}],server_time,notice. Seller/admin also reserve_price_bdt; public never raw bidder customer IDs. Response server_time gives display clock offset; server always validates deadlines. Product image urls relative /api/v1; use API origin or authenticated blob loader for draft/archived owner/order images. PATCH product requires expected_version (from Product), stock mutations increment it. Category strings vegetables/fruits/rice_grains/pulses/other. Unit strings kg/g/piece/bundle/crate. AddressCreate keys name,phone,line1,district,area,country=Bangladesh,latitude?,longitude?. GET cart includes subtotal_bdt and delivery_fee_notice in addition contract above.
