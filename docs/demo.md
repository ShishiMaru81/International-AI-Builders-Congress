# Three-minute demonstration

1. Open /en or /bn. Create a fresh demo workspace; show the source disclaimer.
2. AgroDoctor: upload a tomato image. Show the uncertainty, quality flags, model version and limitations. Open the saved case, add a local expert-review note and export CSV. An uninstalled model always abstains.
3. FloodCrop: inspect the 24/48/72-hour simulated forecast and explain the illustrative threshold. Show the separately labeled FFWC link. For live weather, first create a farm with explicitly consented coordinates; select LIVE and show provider metadata or the genuine unavailable state.
4. Market: show the synthetic 42/46 BDT/kg wholesale quotes. Enter 400 kg, 0% loss, 500 transport, 100 handling, 0 fees. Expected receipts are 16,200 and 17,800 BDT. They are not profit or guaranteed sales. Show private licensed CSV import.
5. Action Center: inspect shared steps generated by the three modules and mark one complete.
6. Devices: register a virtual ESP32, send a simulation and show persisted raw ADC units. End on Data & models with honest validation limits.
